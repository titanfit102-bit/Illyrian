# Responsible disclosure
This public repository currently contains a fictional, local-only DEMO. Do not post credentials, personal data or exploit details in public issues, PRs, logs or screenshots.
Use the repository **Security → Report a vulnerability** private channel if GitHub makes it available. If unavailable, ask the maintainer for a private reporting route without publishing details. A verified private contact and private advisory availability are currently UNKNOWN; no response-time SLA is promised.
Report affected revision, impact and a minimal fictional reproduction privately. Do not test real users, production data or third-party services without authorization. Never commit an unresolved sensitive exploit to this public repository.
Development policy and evidence: [security register](docs/security/SECURITY_REGISTER.md).
